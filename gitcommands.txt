1. git init -> to initiallize an empty repo

2. git add <file_name> -> to stage the file_name

3. git status -> to check the status of the repo

4. git commit -m "<message>"   -> to make the commit to track the file.

5. git remote add origin <url>  -> to add the origin where the pushed code will be delivered.

6. git remote set-url origin https://token@github.com/iam-misam/github-workshop.git

6. git remote -v  -> to check 

7. git push origin <branch_name>

7. git pull origin <branch_name> -> to get the changes in your local from github.
